# Mathematical methods

For a layer/task cloud H∈R^(N×d), X=H−mean_rows(H), X=UΣVᵀ. Float64 economy SVD returns min(N,d) singular values, including numerically zero values. λ_i=σ_i²/(N−1), with omitted ambient covariance eigenvalues implicitly zero. No positive spectrum truncation enters PR or effective rank. A centered cloud identifies at most min(N−1,d) nonzero directions; larger N can change all estimates. Explained fractions λ/Σλ, cumulative fractions and thresholds 80/90/95/99% are reported independently.

Numerical rank counts σ_i>max(N,d)*eps64*σ_max by default; optional relative tolerance is exposed in the estimator API. A singular-value tolerance rather than a covariance eigenvalue threshold avoids squaring the condition number. Positive numerical noise is retained in the full available spectrum and usually contributes negligibly. Zero total variance returns undefined (JSON null) dimension estimates, not arbitrary 0/1. The condition number uses only retained singular directions and is not the ambient covariance condition number when rank-deficient.

Participation ratio: PR=(Σλ)²/Σλ². Covariance effective rank: p_i=λ_i/Σλ, erank=exp(−Σp_i ln p_i). 0 ln 0=0. For r positive covariance eigenvalues, entropy/log(r) is reported, with normalized entropy defined as 0 for r=1; undefined for zero variance. r here counts positive eigenvalues, which can include numerical tails, and differs from tolerance-based numerical rank. Both metrics are scale invariant. Spectra are rescaled by their maximum before computing probabilities and PR to avoid overflow. Substantial negatives raise; tiny negatives (10*eps*length*max_abs_spectrum) are clipped and counted.

PR emphasizes large directions through a quadratic concentration penalty; entropy effective rank weights the distribution differently. Roy & Vetterli's original matrix effective rank uses normalized singular values. Our convention applies their entropy functional **to covariance eigenvalues**, as specified for this study; it is not claimed identical to the singular-value effective rank of the activation matrix.

## TWO-NN

Euclidean first/second distances exclude the point itself using cKDTree k=3. μ=r₂/r₁≥1. Under approximately constant local density on a smooth d-dimensional manifold, F(μ)=1−μ^(−d), so −log(1−F)=d log μ. Sort μ, use midpoint plotting positions F_i=(i−0.5)/N for i=1..N and discard the largest 10% ratios; fit through the origin: d_hat=(xᵀy)/(xᵀx). Midpoint positions are a documented finite-sample variant of the Facco empirical-CDF fit. The implementation does not claim unbiasedness at every N/d.

At least ten samples are required; this is a software minimum, not a reliability guarantee. Duplicate points invalidate the whole cloud; zero denominators, nonfinite ratios and exact equidistance return undefined. R²<0.8 is flagged poor_fit but the estimate remains visible. R² is an informal CDF fit diagnostic; sorted points are dependent, so it is not a valid goodness-of-fit p-value. High-dimensional distance concentration, curvature, boundaries, nonuniform density and sparse sampling can destabilize TWO-NN. Unit normalization changes distances; standardization can amplify low-variance features. Subsampling sensitivity and distance quantiles/CV are retained.

## Preprocessing

Raw mode centers only in covariance estimators; Euclidean distances are translation invariant. Unit mode normalizes each raw row before covariance centering. Standardized mode centers and divides each feature by sample SD (ddof=1); exactly constant features become zero. Bootstrap replicates refit this preprocessing; no full-cloud fitted statistics leak into resampled standardized analyses. These are different geometries and have distinct output labels. A 2D PCA plot is a visualization, not an estimator of intrinsic dimension.

## Sampling and inference

Cloud-level differences/ratios are effect sizes; no per-row dimension samples exist. Family bootstrap samples entire families with replacement within each category, preserves all their prompts and estimates cloud geometry again. Cluster sizes make sample counts vary; this is a standard cluster-bootstrap target, distinct from common-count descriptive estimates. Few family clusters, reused entities and semantic dependence limit validity. Minimum families is configurable and should be increased for publication; four is only an exploratory floor.

TWO-NN bootstrap is disabled because replacement creates exact duplicates. Repeated without-replacement subsampling reports sensitivity, not confidence intervals. Equal-count selection may retain only a subset of a family; the bootstrap conditions on observed selected family clouds. Default natural task-specific template families are not presumed exchangeable. No p-value is emitted by default. If explicitly justified, pooled complete-family permutations repartition families preserving family count; this tests exchangeability of family clouds, a stronger null than equal PR, and can vary prompt counts. It cannot be justified merely by equal category sample counts.

Percentile confidence limits are quantiles at (1−confidence)/2 and 1−(1−confidence)/2. Require at least 20 and 80% valid configured replicates. Two-sided permutation p=(1+# |permuted difference|≥|observed difference|)/(1+valid permutations). BH is implemented and tested; BY is pipeline default, with harmonic factor Σ1/i for arbitrary dependence. Correction families: raw primary PR across layers, and a separate secondary/preprocessing/control family. Undefined tests remain null. Significance is never deduced from interval overlap. The primary directional hypothesis uses a conservative two-sided test plus observed direction.

Centering sensitivity is established through translation-invariance tests; uncentered second-moment spectra are not mixed into covariance comparisons. Levina–Bickel and formal calibrated TWO-NN goodness-of-fit testing are optional deferred extensions.

## Version-2 implementation update

Primary point estimates/rank diagnostics retain economy SVD. Bootstrap spectra can use the equivalent centered N×N Gram covariance matrix when N<d, validate numerical negatives and apply the same full-spectrum formulas. This speeds resampling; tests check Gram/SVD agreement, including duplicate resampling rows and constant features. Raw-mode conditional intervals use 500 replicates; unit/standardized modes are descriptive by default. All-zero final-token embeddings are excluded from primary block inference, with the reason recorded. P-values remain unperformed without justified task-family exchangeability. Ten nominal families supports more observed variability than two but does not prove independently sampled clusters or calibrated population-level inference.
